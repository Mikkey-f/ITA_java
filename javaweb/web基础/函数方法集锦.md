## 一.List

## 1.Arrays.asList

```java
Arrays.asList(emp.getId())将一个元素转换成List集合
```



### 2.

```java
List<Object> jobList = list.stream().map(datamap -> datamap.get("pos")).toList();
List<Object> dataList = list.stream().map(datamap -> datamap.get("num")).toList();
```

这段代码使用 Java Stream API 从 `List<Map<String, Object>>` 类型的数据集合中提取特定字段，并将结果转换为两个独立的列表。以下是对其结构的详细分析：

### **代码结构拆解**

#### **1. 整体功能**

将数据库查询结果（`list`）中的职位名称（`pos`）和人数（`num`）分离为两个独立的列表，用于后续数据处理或前端展示。

#### **2. 关键组件**

- **数据源**：`list` 是一个 `List<Map<String, Object>>`，每个 `Map` 代表一行数据库记录，包含 `pos` 和 `num` 两个键。

- Stream 操作

  ：

  1. `list.stream()`：将列表转换为流。
  2. `map(...)`：对流中的每个元素（`Map`）执行转换操作。
  3. `toList()`：将流中的元素收集为列表（Java 16+ 特性）。

#### **3. 类型处理**

- **返回类型**：`List<Object>`，因为 `Map.get("pos")` 和 `Map.get("num")` 返回的是 `Object` 类型。

- 实际数据类型

  ：

  - `pos` 对应的值应为 `String`（职位名称）。
  - `num` 对应的值应为 `Long` 或 `Integer`（SQL 查询中的 `count(*)` 返回数值类型）。

### **详细解释**

假设 `list` 的数据结构如下（从之前的 SQL 查询结果映射而来）：

```java
[
  {pos=教研主管, num=3},
  {pos=讲师, num=2},
  {pos=其他, num=1}
]
```



#### **1. 提取职位名称列表**

```java
List<Object> jobList = list.stream()
    .map(datamap -> datamap.get("pos"))  // 提取每个 Map 中的 "pos" 键对应的值
    .toList();  // 收集为列表

// 结果：["教研主管", "讲师", "其他"]
```



#### **2. 提取人数列表**

```java
List<Object> dataList = list.stream()
    .map(datamap -> datamap.get("num"))  // 提取每个 Map 中的 "num" 键对应的值
    .toList();  // 收集为列表

// 结果：[3, 2, 1]
```



## 二.String类

### 1.String.indexof

`String`类的`indexOf`方法用于在字符串中查找指定字符或子字符串首次出现的位置

```java
int i = message.indexOf("Duplicate entry"); // 获取异常信息中包含的字符串所在位置
```

#### **基本语法**

1. **查找字符**

   ```java
   int indexOf(int ch)
   ```

   - 查找字符`ch`（Unicode 码点）首次出现的索引。
   - 

2. **从指定位置查找字符**

   ```java
   int indexOf(int ch, int fromIndex)
   ```

   - 从索引`fromIndex`开始查找字符`ch`。

3. **查找子字符串**

   ```java
   int indexOf(String str)
   ```

   - 查找子字符串`str`首次出现的索引。

4. **从指定位置查找子字符串**

   ```java
   int indexOf(String str, int fromIndex)
   ```

   - 从索引`fromIndex`开始查找子字符串`str`。

     

#### **返回值**

- **成功找到**：返回第一次出现的索引（从 0 开始）。
- **未找到**：返回`-1`。



### 2. toLowerCase()

`toLowerCase()` 是 Java 中 `String` 类的一个内置方法，用于将字符串中的所有**大写字母**转换为**小写字母**，并返回一个新的字符串。原字符串不会被修改，因为 `String` 在 Java 中是不可变的。

#### **字符转换规则**

- **大写字母**（如 `A-Z`）会被转换为对应的小写字母（如 `a-z`）。
- **非字母字符**（如数字、标点符号、空格）保持不变。
- **特殊字符**（如 Unicode 中的非 ASCII 字母）也会被转换为小写形式（如果存在对应的小写版本）。



### 3.substring

`substring()` 是 Java 中 `String` 类的一个内置方法，用于从原字符串中提取指定范围的子字符串。它返回一个新的字符串，不会修改原字符串。

#### **基本语法**：

Java 提供了两种重载形式：

1. **提取从起始索引到末尾的子字符串**

   

   ```java
   String substring(int beginIndex)
   ```

   - **参数**：`beginIndex` 是起始索引（包含），索引从 0 开始。
   - **返回值**：从 `beginIndex` 到原字符串末尾的子字符串。

2. **提取指定区间的子字符串**

   

   ```java
   String substring(int beginIndex, int endIndex)
   ```

   - 参数

     ：

     - `beginIndex`：起始索引（包含）。
     - `endIndex`：结束索引（**不包含**）。

   - **返回值**：从 `beginIndex` 到 `endIndex-1` 的子字符串。



### 4.split

`split()` 是 Java 中 `String` 类的一个内置方法，用于根据指定的**分隔符**将字符串拆分为多个子字符串，并返回一个字符串数组。

#### **基本语法**

Java 提供了两种重载形式：

1. **使用正则表达式拆分字符串**

   

   ```java
   String[] split(String regex)
   ```

   - **参数**：`regex` 是正则表达式，表示分隔符的模式。
   - **返回值**：拆分后的字符串数组。

2. **限制拆分次数**

   

   ```java
   String[] split(String regex, int limit)
   ```

   - 参数
     - `regex`：正则表达式分隔符。
     - `limit`：限制拆分的次数，数组长度最大为 `limit`。
   - **返回值**：拆分后的字符串数组。





## 三.Integer

`Integer.parseInt()` 是 Java 中用于将字符串转换为 `int` 类型的静态方法

- **参数**：`s` 为需要转换的字符串。
- **返回值**：转换后的 `int` 类型数值。
- **异常**：若字符串无法正确转换为整数，会抛出 `NumberFormatException`。

- 参数

  ：

  - `s`：待转换的字符串。
  - radix：进制基数（2~36），例如：
    - `2`：二进制。
    - `8`：八进制（字符串可省略前导 `0`）。
    - `10`：十进制（默认值）。
    - `16`：十六进制（字符串可省略前导 `0x`）。
