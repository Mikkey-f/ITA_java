## 一. 实现方案一

在启动类上的配置：

```java
// 自动配置实现方案一
@ComponentScan(basePackages = {"com.example","com.itheima"}) // 指定扫描的包，使用后@SpringBootApplication的组件扫描功能将失效
@SpringBootApplication//具备组件扫描功能，但是默认扫描的是启动类的包及子包
public class SpringbootWebConfigApplication {

    public static void main(String[] args) {
        SpringApplication.run(SpringbootWebConfigApplication.class, args);
    }

}
```
