## 三. 条件分页查询

![image-20250616202646085](C:\Users\24709\AppData\Roaming\Typora\typora-user-images\image-20250616202646085.png)



```mysql
select e.*, d.name from emp e left join dept d on e.dept_id = d.id
                   where e.name like '%阮%' and e.gender = 1 and e.entry_date between '2010-01-01' and '2020-01-01'
                   order by e.update_time desc ;
```

我们发现这条语句太长了，所以准备写在resources文件下，准备一个xml映射文件配置sql语句

<img src="C:\Users\24709\AppData\Roaming\Typora\typora-user-images\image-20250616204745143.png" alt="image-20250616204745143" style="zoom: 67%;" />

错误：like  '%#{name}%'  编译后#{}被替换为？ 变成 ‘%？%’ 这个字符串，就不能填入参数，所以在引号之内不能使用#{}

mysql中的字符串拼接函数 concat

```mysql
select concat('%','阮','%')；

select e.*, d.name from emp e left join dept d on e.dept_id = d.id
                   where e.name like concat('%','阮','%') and e.gender = 1 and e.entry_date between '2010-01-01' and '2020-01-01'
                   order by e.update_time desc ;
```
